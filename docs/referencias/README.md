# Artículos de referencia

Copias locales aportadas para el análisis de la tesis. Los PDF de este directorio están excluidos de Git por `.gitignore`; este índice sí se puede versionar. La presencia de una copia local no implica permiso para redistribuirla en el repositorio ni en Overleaf.

| Archivo | Referencia | Relación con el estudio |
| --- | --- | --- |
| `Didactica_Universitaria_documentacion.pdf` | García y Puig, *Supervised texture classification by integration of multiple texture methods and evaluation windows*, Image and Vision Computing 25 (2007), 1091–1106. DOI: 10.1016/j.imavis.2006.05.023. | Antecedente de integración de métodos y ventanas; clasificación por píxel, no por imagen. El nombre del archivo no describe su contenido. |
| `1-s2.0-S0031320310002062-main.pdf` | Puig, García y Meléndez, *Application-independent feature selection for texture classification*, Pattern Recognition 43 (2010), 3282–3297. DOI: 10.1016/j.patcog.2010.05.005. | Selección de métodos de textura independiente de la aplicación; contrasta con nuestra selección anidada específica por dataset. |
| `1-s2.0-S0167865514002451-main.pdf` | Khan et al., *Compact color–texture description for texture classification*, Pattern Recognition Letters 51 (2015), 16–22. DOI: 10.1016/j.patrec.2014.07.020. | Concatenación de cinco descriptores, color y compresión DITC; FMD y KTH-TIPS-2b compartidos, con protocolos distintos. |
| `CIN2022-9510987.pdf` | Simon y Uma, *DeepLumina: A Method Based on Deep Features and Luminance Information for Color Texture Classification*, Computational Intelligence and Neuroscience (2022), 9510987. DOI: 10.1155/2022/9510987. | Fusión de características profundas y luminancia; DTD y FMD compartidos. |
| `applsci-13-01291.pdf` | Ataky et al., *Multiscale Analysis for Improving Texture Classification*, Applied Sciences 13 (2023), 1291. DOI: 10.3390/app13031291. | Pirámide gaussiana-laplaciana y fusión multiescala. Usa KTH-TIPS original y Outex TC 00011-r, no nuestras variantes KTH-TIPS2-b y Outex TC 00013. |
| `1-s2.0-S0957417423026027-main.pdf` | Chang, Ji y Zhu, *Multi-scale LBP fusion with the contours from deep CellNNs for texture classification*, Expert Systems with Applications 238 (2024), 122100. DOI: 10.1016/j.eswa.2023.122100. | Fusión de LBP multiescala y contornos; usa KTH-TIPS2-b, pero su partición no separa muestras físicas como la nuestra; su Outex TC 00012 no es nuestro Outex TC 00013. |
| `1-s2.0-S095070512600225X-main.pdf` | Gupta, Mishra y Shrivastava, *HyTexNet: Percentile-guided local encoding and deep feature fusion for enhanced texture classification*, Knowledge-Based Systems 338 (2026), 115482. DOI: 10.1016/j.knosys.2026.115482. | Codificación local adaptativa y DenseNet-121; KTH-TIPS2-b y DTD compartidos, con particiones diferentes. |
| `applsci-16-05743-v2.pdf` | Gupta, Mishra y Shrivastava, *AsTexNet: A Discriminative Scale-Aware Hybrid Texture Representation with Compact Embedding*, Applied Sciences 16 (2026), 5743. DOI: 10.3390/app16125743. | Ponderación de escalas, MobileNetV2 y PCA; FMD y KTH-TIPS2-b compartidos. El protocolo KTH 3/1 se parece al nuestro, pero no consta identidad de particiones ni de entrenamiento. |

Los porcentajes publicados no deben convertirse en una comparación directa con nuestra tesis sin verificar imágenes, particiones, métrica, selección de hiperparámetros y preentrenamiento bajo el mismo protocolo.
